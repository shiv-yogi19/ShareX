ShareX Storage-Free Architecture

How does ShareX operate without cloud storage?
Traditional file-sharing sites upload your private files to centralized servers or cloud buckets (like S3 or Google Drive). ShareX establishes a direct peer-to-peer WebRTC connection between devices.

What role does the server play?
The Cloudflare Worker acts solely as a signaling coordinator to exchange session codes, SDP offers, and ICE network candidates. Zero file bytes ever touch the server.

Integrity & Security:
All file transfers are streamed in 64KB binary chunks with SHA-256 cryptographic verification over TLS/DTLS encrypted channels.
